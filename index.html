    AI 사진 판독

    키는 이 기기에만 저장되고, 사진을 판독할 때 Anthropic으로만 전송돼요. 판독 한 번마다 소액의 API 요금이 들어요.

    최근 7일

    사용 방법

    ✓ 체크하기
    항목을 누르면 체크되고 확인한 시각이 남아요. 다시 누르면 체크가 풀려요.
    📷 사진으로 남기기
    항목 오른쪽 📷를 눌러 사진을 찍으면 사진과 함께 체크돼요. 밖에서 “잠갔나?” 싶을 때 작은 사진을 누르면 크게 볼 수 있어요.
    🌙 매일 새로 시작
    자정이 지나면 체크가 모두 비워져요. 지난 결과는 아래 “최근 7일”에 남아요.
    ✏️ 항목 바꾸기
    오른쪽 위 “편집”을 누르면 항목을 추가하거나 삭제할 수 있어요. 끝나면 “완료”를 눌러요.
    📱 홈 화면에 추가
    안드로이드는 크롬 메뉴(⋮) → “홈 화면에 추가”, 아이폰은 사파리 공유 버튼 → “홈 화면에 추가”. 앱처럼 아이콘으로 열리고 인터넷 없이도 돼요.
    🤖 AI 사진 판독 (선택)
    “편집”에서 Anthropic API 키를 넣으면, 찍은 사진을 AI가 보고 완료 상태가 확실할 때만 체크해요. 키가 없어도 나머지 기능은 모두 쓸 수 있어요.
    🔒 내 기록은 내 폰에만
    체크 기록과 사진은 이 기기에만 저장돼요. 다른 사람에게 보이지 않아요.
